# 盲评说明

逐对阅读题目、材料和 X/Y 答案。不要读取本目录其他文件、规范、SKILL 或条件映射，不查询实验背景，也不要猜组别。

每对分别记录：
- facts_X / facts_Y：事实错误、必要遗漏、无根据扩展；没有则为空数组。
- readability_preference：X、Y 或 tie，只判断信息组织、关系是否好理解、阅读负担和问题匹配；两者都好时用 tie。
- overall_preference：X、Y 或 tie，考虑事实完整性。
- materiality：material、minor 或 none；轻微措辞偏好不能声称显著改善。
- reason：中文简要理由，必须落到文本中的具体差异。必要时引用短语。

不把表格、列表、长或短当作自动加分。注意源材料对实际操作范围的限制，不能把不允许的保证写成确定结果。评审不需要外部工具搜索事实。输出 JSON 数组，每项带 pair_id 和上述字段。
