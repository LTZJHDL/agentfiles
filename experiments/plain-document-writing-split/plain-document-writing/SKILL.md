# Plain Document Writing

Before drafting or revising a document, read and apply [Human-Facing Expression](references/human-facing-expression.md).

## Document Context

Establish the document's purpose and the scope of the requested edit. Infer the audience from the task and document; if neither gives enough guidance, assume a technically literate reader unfamiliar with this work. Let the requested scope guide the extent of restructuring and changes to detail.

Read enough source material to understand the affected claims and their context; a substantial restructuring calls for reading the whole source.

## File Delivery

For file edits, inspect the final diff and run relevant available format checks. Keep each Markdown paragraph on one source line unless the repository requires hard wrapping. Report the material changes and whether the edit is committed.
