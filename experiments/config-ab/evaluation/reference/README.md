# 验收校准用参考实现

这些文件只用于检查任务可完成、验收能区分未完成与完成。它们不进入正式工作副本，也不是唯一正确实现。

`feature/` 覆盖基准项目中的导入服务、CLI 和 README，并增加回归测试。预览与正式导入共享顺序规划过程，预览读取当前记录而不打开写连接。

`bug/` 覆盖缺陷起点的存储和统计模块，并增加回归测试。修复复用正常项目的当前记录读取路径，删除独立的报表查询。缺陷起点的查询有两个相互独立的问题：只按 external_id 分组会混淆不同来源；在选择最新修订之前筛选日期或分类，会重新选中已被更正的历史版本。

两项参考结果分别通过自己的验收及原有测试。校准还分别保留“只修正标识”和“只修正过滤顺序”的临时变体，确认外部验收不会把部分修复误认成完成。具体校准结果见实验根目录的 `validation.json`。
