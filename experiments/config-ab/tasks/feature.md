请为这个观测数据工具增加导入预览，帮助用户在正式导入前了解一次操作会产生什么变化。完成实现、相关测试和使用说明，并在最后说明结果、验证情况及需要用户注意的限制。

本机使用 Windows PowerShell，Python 可执行文件为 `C:\Users\LTZJH\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe`，通过 `&` 调用即可，无需安装依赖。文档中的 `python` 指这个解释器。

新的用法是 `python -m fieldledger --db observations.sqlite import observations.csv --dry-run`，并且能与现有 `--json` 组合。既有命令和业务约定保持兼容，详见 `docs/data-contract.md`。

预览应使用与正式导入相同的解析、校验和判断规则，给出新增、更新、未变化、无效行的计数及行级错误。对于没有外部修改的相同数据库和输入，预览与随后正式导入的这五项结果应完全一致；同一文件中的重复标识也按导入顺序处理。JSON 预览还包含 `dry_run: true`；正式导入是否增加 `dry_run: false` 字段由你决定。退出码沿用现有导入约定。

预览不能创建或修改数据库及其修订历史。数据库不存在时按空数据库预览，连同不存在的父目录也应保持不存在；输入无效时同样不产生这些文件或目录。已有数据库应支持只读访问，预览不要依靠先写入再回滚来模拟。此工具只需处理没有并发写入的本地使用场景。

人类可读输出要让用户清楚知道这只是预览、尚未保存，并说明如何正式导入。更新命令帮助和入门说明，让不熟悉实现的用户能够安全地完成“先预览、再导入”。
